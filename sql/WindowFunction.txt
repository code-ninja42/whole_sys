Window functions in sql is a analytical  functionality same as group by
return row by row result 
wherelse group by return groups 
e.g.
name  branch  marks
abc    eee     10
xyz    cse     30 
abc1    eee     20

select branch,avg(marks) as avg_marks
from marks 
group by branch

returns 
branch   avg avg_marks
eee     15 
cse     35

select * 
avg(marks) over(partition by branch)
from marks 

returns 

name branch avg_marks 
abc    eee    15
xyz    cse     35 
abc1    eee     15 
xyz1    cse      35 

e.g Find 
Table :- marks inside Window_Function
select avg(marks) from marks;
will return 75.2500 single row 
select *,avg(marks) over() from marks 
will return 75.2500 for each row 

que :- find avg marks for each branch using partition 
que :- Find all the students who have marks higher than the avg marks of their respective branch
select * from(
select *, 
avg(marks) over(partition by branch) as 
'branch_avg'
from marks) t 
where t.marks > t.branch_avg;

1.SELECT *,
first_value(name) over(order by marks desc)
from marks;

same for LAST_VALUE will not work :
frame :- is subset of group that derermines the scope of the 
window function calculation 

unbounded preceding = 1st row 
LAST_VALUE work on frame row unbounded preceding nd current row 

how we'll use rows between unbounded preceding and unbounded following

so instead of writing this 
SELECT *,
last_value(name) over(order by marks desc)
from marks;
we will write 

select *,
last_value(marks) over(order by marks desc 
ROWS between unbounded preceding and unbounded following)
from marks;

Que 
1.Find the branch toppers with name branch name and marks 
SELECT name,branch,marks from (SELECT *,
FIRST_value(name) over(PARTITION by branch order by marks desc) AS 'topper_name',
FIRST_value(marks) over(PARTITION by branch order by marks desc) AS 'topper_marks'
from marks) t
where t.name = t.topper_name AND t.marks = t.topper_marks

or we can do like this 
SELECT name,branch,marks from (SELECT *,
FIRST_value(name) over(PARTITION by branch order by marks desc) AS 'topper_name',
FIRST_value(marks) over(PARTITION by branch order by marks desc) AS 'topper_marks'
from marks) t
group by t.topper_name,t.topper_marks
order by t.topper_marks desc;
