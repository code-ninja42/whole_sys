Import ABC and abstractmethod from abc.

Make the parent class inherit from ABC.

Mark the abstract method with @abstractmethod.

The abstract method can have no implementation, often written with pass.

A child class must implement the abstract method before you can create an object of that child class.

Example
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def sound(self):
        pass

class Dog(Animal):
    def sound(self):
        print("Bark")

d = Dog()
d.sound()
